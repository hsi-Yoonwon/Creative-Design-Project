# ThingSpeak + IFTTT 휴대폰 알림

ThingSpeak 채널의 가변저항 값(field1)이 800을 넘으면 React → ThingHTTP → IFTTT Webhook을 거쳐 휴대폰 IFTTT 앱으로 알림을 보내는 과제입니다.

👉 **[프로젝트 페이지 보기](https://hsi-yoonwon.github.io/Creative-Design-Project/thingspeak-alert/)**: 전체 흐름, IFTTT Applet, ThingHTTP, React, API Request, 알림 확인, 어려웠던 점
